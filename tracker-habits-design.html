Reasoning, written down (R-31)

  • Weekday dots are the identity motif. The exact is-on / is-scheduled / is-off vocabulary already ships on the Dashboard; Habits extends it, it does not invent a new chart.
  • State never rides on color alone. Checked = filled, scheduled = solid outline, off = dashed + dimmed, plus a text legend and aria-labels. Meets WCAG for color-blind use.
  • Fixed zone is stated, not hidden. "Asia/Jakarta (fixed) since <date>" sits under each name because the PRD makes the habit zone immutable and load-bearing for check-in dates.
  • Ratio is a fraction, not a percentage. "3/4 check-ins this week" matches how the PRD counts (check-ins over scheduled days); a habit with no scheduled days would read "No scheduled days", never a fake 0%.
  • Edit-schedule modal warns before it saves. "Takes effect tomorrow in this habit's zone; today keeps the current schedule" is shown inline, because that is the real server rule.
  • Archived is read-only but honest. The form is locked yet history stays correctable, exactly the SCHEMA rule, rather than hiding the habit entirely.
  • One accent, few places. Green lands on checked dots, the primary check-in button, and the active nav icon: nowhere else.
  • Fraunces on the ratio number. The one big figure per card uses the display serif, the editorial-number motif from DESIGN.md; every weekday label stays in Inter.
