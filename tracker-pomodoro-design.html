How to read this file. The main timer is live: Start, Pause, Resume, and Cancel really work and the ring counts down. Reasoning, written down (R-31)

  • The timer is the single focal point. One big Fraunces number inside one accent ring; everything else on the screen defers to it.
  • The ring is a function, not decoration. Its single accent stroke shows time elapsed, so it earns the accent under MOTION 1 (it advances with the countdown, it does not loop for effect).
  • Phase is text, not color. Focus / Short break / Long break all use the same chip; the ring stays one green. A color-coded phase would spend the accent on decoration.
  • Focus count is pips plus text. "2 of 4 focus sessions today" pairs shape with a sentence, so the progress toward a long break never depends on seeing color.
  • No auto-advance. After a terminal phase the screen shows an explicit "Start next phase", matching the server rule that the next phase never starts on its own.
  • Cancel is honest. The confirmation states that elapsed time stays on record but does not count as a completed Pomodoro, and cancelled rows use the hatch, not a red badge.
  • Waiting state is real. When the local countdown hits zero it shows "Waiting for phase completion" instead of switching phase on the client, because only the server closes a phase.
  • Durations are fixed. 25 / 5 / 15 are shown, never editable, matching the MVP decision, so there is no settings surface to fake.
