Reasoning, written down (R-31)

  • No priority colors. Low/Medium/High are plain text chips, identical treatment. DESIGN.md bans decorative capsule badges; color would make priority a decoration, not information.
  • Hatch flag reused for Overdue. Same pattern already used for Timebox "Schedule overlap" on the Dashboard — one identity motif for "needs attention", not a new red icon.
  • No drag-only Kanban. UX-FLOWS requires a non-drag alternative; the per-card status select is that alternative, not an add-on.
  • Mark done stays enabled visually, disabled functionally when blocked (see the task detail modal) — the blocking predecessor is named, never a silent disable.
  • Fraunces stays on headings only. "Tasks" and the empty-state title use it; every data row stays in Inter with tabular numbers for the due-date column, matching Monarch's tidy-number reference.
  • One accent, three places. Green appears on the active nav icon, primary buttons, and a completed checkbox: nowhere else on this screen.
